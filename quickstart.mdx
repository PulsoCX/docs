## Prerequisites

You need:

- A Pulso tenant and a published `pulsoVersion`. Both are created from the Pulso console (`https://console.pulso.cx`); the version id is shown on the Pulso detail page.
- An API key from the console with the `conversations:write` scope. Keys look like `pk_live_...`.
- A destination the customer can reach: a phone in E.164 format (`+56982959775`), an email address (`maria@example.com`), or both, depending on the channel you want to demo.

## Trigger a conversation

All three channels share the same endpoint. The body discriminates which outbound action Pulso runs.

<CodeGroup>

```bash Phone
curl -X POST https://api.pulso.cx/v1/conversations \
  -H "Authorization: Bearer pk_live_..." \
  -H "Content-Type: application/json" \
  -d '{
    "pulsoVersionId": "1f915ea6-04b2-4232-884d-ccfb1773cf9a",
    "channel": "phone",
    "channelMetadata": { "phoneE164": "+56982959775" }
  }'
```

```bash Email
curl -X POST https://api.pulso.cx/v1/conversations \
  -H "Authorization: Bearer pk_live_..." \
  -H "Content-Type: application/json" \
  -d '{
    "pulsoVersionId": "1f915ea6-04b2-4232-884d-ccfb1773cf9a",
    "channel": "email",
    "channelMetadata": { "email": "maria@example.com" }
  }'
```

```bash WhatsApp
curl -X POST https://api.pulso.cx/v1/conversations \
  -H "Authorization: Bearer pk_live_..." \
  -H "Content-Type: application/json" \
  -d '{
    "pulsoVersionId": "1f915ea6-04b2-4232-884d-ccfb1773cf9a",
    "channel": "whatsapp",
    "channelMetadata": { "phoneE164": "+56982959775" }
  }'
```

</CodeGroup>

A successful call returns `201 Created` with the new `conversationId`:

```json
{
  "conversationId": "54956fe0-2613-42bc-8708-839ee500f228",
  "startedAt": "2026-05-15T07:03:25.264Z"
}
```

## What happens next

- **Phone**: Twilio places the outbound call within a couple of seconds. The customer answers and the AI agent speaks first.
- **Email**: SES delivers a transactional invitation with a signed link to `chat.pulso.cx/p/{shareSlug}?ct=...`. Clicking it lands the customer directly in the web chat, already identified.
- **WhatsApp**: Meta delivers the approved `pulso_es` template. The customer answers in the same thread and the agent replies; double check (read receipt) and typing indicator are surfaced automatically.

The conversation, its transcript, and the downstream analysis + action plan are visible in the Pulso console as soon as they happen.
